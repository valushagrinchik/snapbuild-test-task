# SnapBuild Landing Page - Modern Next.js Implementation

## 1. Краткое описание выполненной работы

Проект представляет собой современную реализацию лендинга платформы Снэпбилд на Next.js 16, полностью основанную на анализе оригинального сайта snapbuild.ru. Проект создан с нуля с чистой модульной архитектурой React компонентов, использующей оригинальные CSS стили для точного воспроизведения дизайна.

## 2. Ссылка на опубликованную страницу

Локальная версия: http://localhost:3000
Оригинальный сайт: https://snapbuild.ru/

## 3. Инструкция по локальному запуску

```bash
# Установка зависимостей
npm install

# Запуск development server
npm run dev

# Открыть в браузере
http://localhost:3000

# Production build
npm run build
npm start
```

## 4. Использованный стек

- **Next.js 16.3.1** - React фреймворк для production-ready приложений
- **React 19.2.8** - библиотека для построения пользовательских интерфейсов
- **TypeScript 5** - типизированный JavaScript
- **Оригинальный CSS** - стили с snapbuild.ru для точного воспроизведения дизайна

## 5. Структура проекта

```
src/app/
├── components/          # Модульные React компоненты
│   ├── Header/         # Навигация с мобильным меню
│   ├── Hero/           # Главная секция
│   ├── Logos/          # Бегущая строка логотипов
│   ├── Process/        # Секция процесса
│   ├── Features/       # Безопасность
│   ├── Roadmap/        # Роадмап
│   ├── FAQ/            # Аккордеон с FAQ
│   ├── CTA/            # Призыв к действию
│   └── Footer/         # Футер
├── layout.tsx          # Корневой layout с подключением CSS
├── page.tsx            # Главная страница
└── globals.css         # Глобальные стили

public/original/        # Оригинальные файлы сайта
├── assets/             # Все ассеты (css, js, files, images)
├── body-content.html   # Извлеченная body часть
└── original.html       # Полный HTML оригинального сайта
```

## 6. Особенности реализации

**Архитектура:**
- Модульная структура компонентов для легкой поддержки
- Использование оригинальных CSS классов для точного воспроизведения дизайна
- Клиентская интерактивность (useState, useEffect)
- Адаптивный дизайн с fluid typography

**Интерактивность:**
- Мобильное меню с состоянием
- Scroll эффект для header
- Аккордеон для FAQ
- Плавная прокрутка к секциям

**Оптимизация:**
- Static Site Generation (SSG)
- Оптимизированные изображения
- Минимальный bundle size
